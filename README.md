# @themis-ui/datagrid

A reusable, type-safe React DataGrid component built with TypeScript and Tailwind CSS.

The DataGrid supports:

- Sorting
- Global search
- Column filters
- Numeric filtering and ranges
- Column visibility
- Column visibility persistence
- Pagination
- Custom cell rendering
- Multiple column types
- Dark mode
